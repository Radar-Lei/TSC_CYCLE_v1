## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> filesystem writes | Maintainer-provided paths can accidentally or maliciously target files outside Phase 17 artifacts. |
| local evidence -> policy gate | Dataset/replay inputs may be malformed, stale, mismatched, or crafted to manipulate denominators. |
| offline policy code -> deployment prompt | Offline saturation band rules must not leak into final inference prompts. |
| report JSON -> downstream phases | Future data/eval/replay phases rely on structured `ok` and `fatal_failures` fields. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-06 | Tampering | `reject_unsafe_phase17_output_path` | mitigate | Resolve candidate and allowed root with `Path.resolve(strict=False)`; only allow `artifacts/v4/phase17/*` writes; tests reject traversal/arbitrary roots. |
| T-17-07 | Tampering | JSON report writer | mitigate | Serialize with `allow_nan=False`, `sort_keys=True`, and safe parent creation only after path guard passes. |
| T-17-08 | Tampering | threshold gate denominators | mitigate | Treat missing/non-finite denominators, malformed rows, and denominator exclusions without explicit counts as fatal failures. |
| T-17-09 | Repudiation | replay evidence | mitigate | Compare Phase 12 manifest/per-sample counts and sample IDs; hash input files when available; stale/mismatched replay evidence blocks `next_phase_allowed`. |
| T-17-10 | Information Disclosure / Tampering | prompt protocol guard | mitigate | Scan prompt output for explicit saturation band snippets and compare deterministic fixture prompt byte-for-byte against v4 golden contract; do not edit prompt builder. |
| T-17-11 | Denial of Service | CLI loading | accept | Phase 17 reads existing bounded local artifacts; no network/GPU stack; large file processing remains linear and local. |
