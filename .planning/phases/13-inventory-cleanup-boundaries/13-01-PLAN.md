Required module contract for `tsc_cycle/cleanup_inventory.py`:
- `build_inventory(repo_root: Path | str = Path.cwd()) -> dict`: returns a JSON-serializable inventory payload without mutating repository assets.
- `write_inventory_json(inventory: dict, output_path: Path | str) -> None`: writes only the specified Phase 13 inventory output file.

- `path`
- `group`
- `classification`
- `recommended_action`
- `phase15_allowed`
- `rationale`
- `risk_if_deleted`
- `evidence_paths`
- `git_status`
- `size_bytes`
- `high_impact`

Allowed classifications:
- `v4 reproduction source`
- `v4 evidence`
- `archived legacy`
- `temporary`
- `removable`

Represent uncertainty only through `recommended_action=manual_review_before_remove` or `phase15_allowed=manual_review_required`; every entry must still use one of the five allowed classifications above.

Allowed recommended actions:
- `keep`
- `archive_candidate`
- `remove_candidate`
- `manual_review_before_remove`
- `keep_or_archive`

Allowed `phase15_allowed` values:
- `no_delete`
- `archive_only`
- `remove_candidate`
- `manual_review_required`
