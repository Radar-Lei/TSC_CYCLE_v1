## Accomplishments

- Refactored `tsc_cycle/teacher/labeler.py` into testable Phase 2 entry points: `build_parser()`, `run_labeling(args, client_factory=TeacherClient)`, and `main()`.
- Added Phase 2 safety controls: worker cap at 10, `OPENAI_API_KEY` preflight for real client execution, cache-dir injection, `--input-files`, `--exclude-labeled`, and protected `data/labeled.jsonl` output rejection.
- Preserved append-only resume semantics by skipping IDs already present in accepted, rejected, and excluded JSONL files before submitting any API calls.
- Preserved lint-drop behavior: failed API/parse/malformed responses and hard-constraint violations are appended to rejected output once and are not requeued.
- Added smoke/full live labeling wrappers that use isolated v3 Phase 2 paths and run `git diff --quiet -- data/labeled.jsonl` before and after labeler invocation.
- Completed human/API smoke verification after rerun: 47 accepted and 3 rejected out of 50, with the frozen baseline unchanged.

## Decisions Made

- Kept prompt text unchanged and extracted orchestration seams around the existing teacher client so RED tests could inject fake clients without network calls.
- Kept Phase 2 new labels physically isolated under `data/v3/phase2/` and refused direct writes to the protected v1 baseline `data/labeled.jsonl`.
- Treated malformed teacher outputs as normal rejected samples, not as retriable samples, matching the plan's lint/parse reject semantics and avoiding budget replay.
