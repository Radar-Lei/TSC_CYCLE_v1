<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell env→OpenAI client | `OPENAI_API_KEY` crosses from environment to SDK and must not be serialized. |
| GPT-5.5 response→accepted labels | Untrusted model output must pass parse and hard-constraint lint before acceptance. |
| previous outputs→resume done set | Existing JSONL progress controls whether paid API calls are repeated. |
| labeler outputs→frozen baseline | New labels must never be written to `data/labeled.jsonl`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-api-key | I | `labeler.py`, wrapper scripts | mitigate | Read key only from env, never log values, and tests check sentinel key is absent from outputs. |
| T-02-budget-replay | D | `run_labeling` done-set | mitigate | Read done IDs from labeled and rejected outputs plus excluded old labels before submitting futures. |
| T-02-baseline-tamper | T | output path guard | mitigate | Reject `data/labeled.jsonl` as output and wrapper scripts run before/after `git diff --quiet -- data/labeled.jsonl`. |
| T-02-malformed-output | T | labeler lint gate | mitigate | Accept only parsed successful results that pass `constraint_lint.validate`; append all others to rejected. |
</threat_model>
