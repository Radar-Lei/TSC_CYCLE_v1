  <action>
    创建 `tsc_cycle/student/parity_prompts.py`，CLI argparse：
      --labeled (default `data/labeled.jsonl`)
      --out (default `runs/20260507T032419Z/gguf/parity_prompts.jsonl`)
      --n-id (default 10)
      --n-ood (default 10)
      --seed (default 42)
      --exclude-trivial (default True，flag --include-trivial 关闭)

    流程：
    1. 流式读 labeled.jsonl，每行 json.loads；
       按 `split_hint` 字段分桶 `id_bucket` 与 `ood_bucket`；
       若 --exclude-trivial 则丢弃 `trivial == True` 的样本。
    2. `random.Random(seed).sample(id_bucket, n_id)` 与 `random.Random(seed+1).sample(ood_bucket, n_ood)`（两个独立 Random 实例避免 OOD 池小于 n_ood 时回退到 id 池）。
       若任一池 < 要求数量，raise SystemExit(f"insufficient samples in bucket {bucket}: have N, need M")。
    3. 合并 selected = id_picks + ood_picks（顺序：先 id 后 ood，方便 plan 03 对应分组）。
    4. 写出：父目录 mkdir parents=True exist_ok=True；逐行 json.dumps(record, ensure_ascii=False) + "\n" append；
       每条记录保留全部原始字段（sample_id / split_hint / trivial / ood_dims / input / solution / usage 等），不剪裁，方便 Plan 03 直接读教师 SOLUTION 做 sanity 对照。
    5. stdout 打印汇总：
       ```
       [PARITY-PROMPTS] selected 10 id + 10 ood = 20 samples
       [PARITY-PROMPTS] sample_ids:
         id:  <id1>, <id2>, ...
         ood: <id1>, <id2>, ...
       [PARITY-PROMPTS] wrote runs/20260507T032419Z/gguf/parity_prompts.jsonl
       ```
       sys.exit(0)
  </action>
