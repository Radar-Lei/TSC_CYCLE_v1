    `python -m tsc_cycle.eval.eval_prompts --labeled data/labeled.jsonl --out runs/20260507T032419Z/eval/eval_prompts.jsonl --n-id 300 --n-ood 300 --seed 42`

    实现要点：
    1. `argparse` 解析参数（默认值如上）
    2. 读 labeled.jsonl 全部行 → list[dict]
    3. 按 `record["split_hint"]` 分桶：`id_pool = [r for r in rows if r["split_hint"] == "id"]`，`ood_pool = [r for r in rows if r["split_hint"] == "ood"]`
    4. 断言 `len(id_pool) >= 300` 且 `len(ood_pool) >= 300`，否则 print 实际数量并 `sys.exit(2)`
    5. `rng = random.Random(42)`；`id_picked = rng.sample(id_pool, 300)`；`ood_picked = rng.sample(ood_pool, 300)`
    6. 对每条 picked record 输出一行 JSON，字段顺序固定：
       ```python
       {"sample_id": r["sample_id"],
        "split_hint": r["split_hint"],
        "input": r["input"],
        "teacher_solution": r["result"]["solution"],
        "phase_count": len(r["input"].get("phases", r["input"].get("phase_min_green", {}))),
        "trivial": bool(r.get("trivial", False))}
       ```
       phase_count 取 `len(r["input"]["phases"])` 若键存在，否则 `len(r["input"]["phase_min_green"])`（兼容两种 schema）
    7. 写出顺序：先 300 id 后 300 ood（不要 shuffle 混合）
    8. 落盘前 `Path(out).parent.mkdir(parents=True, exist_ok=True)`
    9. stdout 打印 `[EVAL-PROMPTS] OK n_id=300 n_ood=300 out={out}`

    严禁：使用 numpy.random / 任何带其他 seed 的 RNG；按 sample_id 排序后再 sample（破坏分布）。
  </action>
