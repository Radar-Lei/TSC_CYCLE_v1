  <action>
    创建 `tsc_cycle/eval/generate_hf.py`。CLI：
    `python -m tsc_cycle.eval.generate_hf --merged-hf runs/20260507T032419Z/merged_bf16 --prompts runs/20260507T032419Z/eval/eval_prompts.jsonl --cache-dir runs/20260507T032419Z/eval/gen_cache/hf_bf16 --n-predict 384`

    实现要点：
    1. argparse 默认值同上
    2. `cache_dir.mkdir(parents=True, exist_ok=True)`
    3. 读 prompts JSONL 为 records list；构造待跑 list：
       ```python
       todo = [r for r in records if not (cache_dir / f"{r['sample_id']}.json").exists()]
       print(f"[GEN-HF] resume: {len(records)-len(todo)} cached, {len(todo)} to generate", file=sys.stderr)
       ```
    4. 若 `len(todo) == 0` → 打印 `[GEN-HF] OK all-cached n=600` 并 `return 0`（不加载模型）
    5. 加载模型（与 parity_hf.py 一致）：
       ```python
       tok = AutoTokenizer.from_pretrained(args.merged_hf)
       model = AutoModelForCausalLM.from_pretrained(
           args.merged_hf, torch_dtype=torch.bfloat16,
           attn_implementation="sdpa", device_map={"": 0})
       model.eval()
       torch.manual_seed(42)
       ```
    6. 复用 `_hf_generate`（直接 import 或复制函数体；建议 `from tsc_cycle.student.parity_hf import _hf_generate`）
    7. 对每条 record（with `torch.inference_mode()`）：
       ```python
       user_prompt = build_user_prompt(rec["input"])
       text = _hf_generate(model, tok, user_prompt, args.n_predict)
       _, sol = parse_assistant_output(text)
       out = {"sample_id": rec["sample_id"], "split_hint": rec["split_hint"],
              "backend": "hf_bf16", "solution": sol,
              "parse_error": None if sol is not None else "solution_unparseable",
              "raw_text": text, "n_predict": args.n_predict, "seed": 42}
       (cache_dir / f"{rec['sample_id']}.json").write_text(
           json.dumps(out, ensure_ascii=False, indent=2), encoding="utf-8")
       ```
    8. 每 10 条打印进度 `[GEN-HF] progress {i}/{n_todo} elapsed={t:.1f}s`
    9. 异常捕获：单条异常不退出，写 `parse_error: f"exception: {type(e).__name__}: {e}"` 并 `solution=None`，继续
    10. 结束打印 `[GEN-HF] OK generated={n_todo} total_cached={len(records)}`

    严禁：sample 模式 / temperature>0 / top_k!=1；packing；`apply_chat_template`；多次 reload 模型；写中间汇总文件（per_sample.jsonl 是 metrics 阶段产物）。

    内存防护：本脚本调用方必须用 `scripts/dgx_spark/run_safe.sh 100G --` 包裹，但脚本内部不需要做 systemd-run（由 caller 处理）。
