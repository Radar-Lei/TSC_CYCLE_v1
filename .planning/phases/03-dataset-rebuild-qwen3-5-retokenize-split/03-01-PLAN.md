<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Phase 2 JSONL fixture -> split logic | Untrusted local JSONL-like rows can contain duplicate IDs, malformed fields, or ambiguous split hints. |
| Tokenizer output -> Arrow artifact | Token IDs and labels become Phase 4 training inputs; silent truncation or native-token leakage corrupts training data. |
| Test tmp_path -> project data paths | Tests must not write to production data paths while defining artifact contracts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-duplicate-split | Tampering | `build_split_plan` contract tests | mitigate | Tests must assert duplicate sample IDs and cross-split overlaps fail closed and produce no artifacts. |
| T-03-path-drift | Tampering | output path tests | mitigate | Tests must assert writes target only tmp_path mirrors of `data/splits/v3` and `data/tokenized/v3`, never `data/labeled.jsonl` or v1-era tokenized paths. |
| T-03-truncation | Integrity/DoS | `tokenize_record` contract tests | mitigate | Tests must assert raw length is computed before truncation and >5% truncation causes ok=false with no Arrow outputs. |
| T-03-reproducibility | Repudiation | manifest/index contract tests | mitigate | Tests must require seed, hashes, source SHA, and v1.0 OOD alignment evidence in persisted artifacts. |
</threat_model>
