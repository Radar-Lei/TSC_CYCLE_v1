## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `reality.log` -> parser | Mixed log file includes trusted prompt JSON and untrusted stale outputs. |
| CLI -> filesystem | CLI paths can target protected or unrelated locations if not guarded. |
| CLI -> llama-server process | Local process/network boundary for model serving. |
| llama-server output -> final artifact | Model text is untrusted until protocol, parse, and hard-constraint gates pass. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | Tampering | `extract_reality_inputs` | mitigate | Regex only extracts framed JSON and never reads old output sections as source facts. |
| T-12-06 | Tampering | `reject_unsafe_phase12_output_path` | mitigate | Reject writes outside final log/tmp and Phase 12 artifact root, and reject frozen v1 root. |
| T-12-07 | Information Disclosure | llama-server lifecycle | mitigate | Reuse localhost `127.0.0.1` `--no-webui` helper and clean process group teardown. |
| T-12-08 | Denial of Service | full 426-sample generation | mitigate | Use per-sample cache, `--resume`, timeout metadata, and one controlled retry for truncation. |
| T-12-09 | Tampering | model output validation | mitigate | Fail closed on parse/lint/protocol errors; do not clamp or repair model-owned outputs. |
